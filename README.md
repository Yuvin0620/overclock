# CLUB OVERCLOCK — 기획서 & 실행 가이드

> 2087년. 로봇이 인류를 '안전하고 건전하게' 보호하는 시대.
> 당신은 로봇 전용 클럽 「오버클럭」의 사장. 보안실 CCTV로 로봇인 척 숨어든 인간을 찾아 **귀가 조치**(바닥 함정 낙하)한다.

장르: XR 관찰·추리 게임 / 톤: 블랙코미디 / 그래픽: 로우폴리 + CRT 감시 화면
엔진: WebXR (three.js) — Quest 브라우저, PC VR, 데스크톱 브라우저 모두 실행

## 0. 메인 화면 — AR 「OVERCLOCK 단말기」

퀘스트는 **START AR**(패스스루)로 시작: 내 방 위에 레트로 컴퓨터 · 디스크 두 장 · CLUB OVERCLOCK 네온 간판이 뜹니다. PC는 같은 물건이 어두운 공간에.
- 디스크를 집어 본체 앞 드라이브 구멍에 대면 쏙 들어감 (PC: 디스크 클릭). 놓으면 제자리로. 다른 디스크를 넣으면 먼저 것은 빠짐
- **오일 디스크 = 감시 모드**, **칵테일 디스크 = 인간 모드** → 화면에 설명 + 번호 목록 → 키보드 숫자 키(PC: 1/2/3 또는 3D 키 클릭)로 튜토리얼 / 플레이 / 하드 모드
- 튜토리얼은 한 번 마치면 목록에서 사라짐 · 하드 모드는 엔딩 후 해금 · 키보드의 한/EN 키 = 언어
- AR 세션 하나로 게임까지 이어짐 (보안실·클럽은 배경이 꽉 차서 완전한 가상 공간)

## 1. 실행 방법

**`index.html` 을 더블클릭하면 끝.** (크롬/엣지 권장, 인터넷 연결 필요 — three.js를 CDN에서 불러옴)

- 데스크톱: 열고 [근무 시작]
- VR(Quest 등)로 하려면 웹에 올려야 합니다(WebXR은 https 필요).
  폴더째로 GitHub Pages / Netlify Drop(드래그&드롭) 등에 올리고 Quest 브라우저로 접속 → ENTER VR
- PC에서 VR 흉내: 크롬 확장 "Immersive Web Emulator"
- PC 조작: 클릭 선택 · 드래그 둘러보기 · **모니터에 우클릭 = 눈앞으로 당기기** · 휠 줌 · 오일 캔/커피 클릭 = 마시기 · S/E/D/Space · **P = PSX 강도**

### VR 조작 (Quest 핸드 트래킹 / 컨트롤러 둘 다)
양손이 **로봇 손**으로 보입니다. 맨손이면 손 관절을 그대로 따라가고, 컨트롤러면 트리거를 당길 때 검지가, 그립을 쥘 때 나머지 손가락이 굽혀집니다.

| 하고 싶은 것 | 방법 |
|---|---|
| 버튼(확인·스캔·귀가 조치) | **검지로 직접 꾹** 눌러야 함 (레이로는 안 눌림, `RAY_BUTTONS`로 변경 가능) |
| DJ 교체 레버 | 노란 손잡이를 **잡고(핀치/그립) 몸 쪽으로 끝까지 당기기** → 철컥! 놓으면 스프링처럼 돌아감 (PC: 아래로 드래그 또는 클릭) |
| 손님 선택 | 모니터를 레이로 가리키고 핀치/트리거, 또는 **화면을 손가락으로 터치** |
| 모니터 당기기 | 모니터를 가리킨 채 핀치/트리거를 0.6초 꾹, 또는 그립 |
| 오일 캔/커피 마시기 | 맨손: 핀치로 집기 · 컨트롤러: 그립으로 집기 → 입 가까이 가져가서 **기울이기** |
| 높이 다시 맞추기 | 아무것도 안 가리킨 상태에서 그립 |

뭘 마셨는지는 엔딩 대사에 반영돼요. (로봇은 커피를 안 마셔요...)

### 그래픽: PSX 스타일
- 텍스처 픽셀 깨짐(32px nearest), 꼭짓점 스냅(지글거림), 아핀 텍스처(바닥 일그러짐), CCTV 디더링
- 글자(패널·포스터·간판)는 왜곡에서 제외해서 선명하게 보이게 함
- P 키: **PSX 선명(기본)** → PSX 강하게(저해상도) → 끔
- VR에서는 보안실 지글거림을 끔 (멀미 방지)

## 2. 음악 넣기 (DJ 곡)

1. `music/` 폴더에 음악 파일을 넣고
2. `index.html` 을 메모장/VS Code로 열어 위쪽의 `const TRACKS = [` 부분에 한 줄씩 추가
   ```js
   { title: '곡 이름', url: 'music/song.mp3', bpm: 124 },
   ```
3. **bpm을 정확히!** 로봇 손님들이 그 박자에 *정확히* 맞춰 춤추고, 인간은 박자를 무시합니다.
4. 6일차(정기 감사) '인간 DJ' 전용 곡은 바로 아래 `HUMAN_DJ_TRACK` 에.

곡이 없으면 내장 신시사이저 비트가 나옵니다. 시작 화면의 [♪ 내 곡 추가] 로 임시로 넣어볼 수도 있습니다(BPM 120 가정).

## 3. XR 설계 — 왜 '보안실'인가

| 결정 | 이유 |
|---|---|
| 플레이어는 좁은 보안실 안에 **고정**(앉거나 서서) | 이동이 없어서 멀미가 없습니다. 앉아서도 플레이할 수 있습니다. |
| 클럽은 **모니터 너머로만** 보임 | "CCTV로 관찰한다"는 컨셉을 그대로 조작으로 만들었습니다. 몰입감이 생기고 렌더링 부담도 줄어듭니다. |
| **레이 포인터 + 트리거** 하나로 모든 조작 | 모니터 속 손님을 직접 가리키면 화면 UV → CCTV 카메라 레이로 변환해서 클럽 안의 손님을 집어냅니다. 핸드 트래킹(핀치)에서도 똑같이 동작합니다. |
| 버튼과 레버는 **책상 위 실물** | 빨간 버튼과 레버가 손에 닿는 위치에 있어서 누르는 맛이 있습니다. 누르면 햅틱 진동이 옵니다. |
| 포스터·벽보로 **정보 전달** | 고개를 돌리면 '인간 식별 요령' 포스터가 보입니다. HUD 대신 공간 안에서 정보를 줍니다. |
| 그립 버튼 = **위치 재조정** | 키와 자세가 달라도 책상 높이를 맞출 수 있습니다. |

## 4. 게임 루프

1. **관찰**: CCTV 4대와 ZOOM 모니터로 손님들을 봅니다.
2. **선택**: 모니터 속 손님을 가리키고 트리거를 당기면 ZOOM 모니터가 그 손님을 클로즈업으로 따라갑니다.
3. **판단**: 아래 단서로 추리합니다. 확신이 없으면 **스캔**합니다(밤마다 2~3회로 제한).
4. **귀가 조치**: 빨간 버튼을 누르면 손님 발밑에 함정이 열리고 "으아아악~" 하며 떨어집니다.
5. **DJ 교체**: 곡이 마음에 안 들면 레버를 당깁니다. DJ가 함정으로 떨어지고, 다음 DJ가 올라오며 다음 곡이 나옵니다.

"사장님은 왜 맨날 보안실에만 계세요?", "보안실 온도가 36.6도..."

손님 이름은 인간·로봇이 **같은 이름 풀**에서 나와서 이름으로는 정체를 알 수 없습니다(튜토리얼 제외).
밤마다 **S~F 등급**이 매겨지고, 피날레에서 밤별 등급을 보여 줍니다.
엔딩(영업 정지 제외)을 한 번 보면 시작 화면에 **★ 하드 모드**가 열립니다: 튜토리얼 생략, 시간 15% 단축, 스캔 1회 감소.

### 엔딩
- **A · 안전하고 건전한 결말**: 빨간 버튼으로 스스로 귀가 조치합니다. 보안실 바닥이 열리고 화면이 암전됩니다. BENE-9가 클럽을 맡고 첫 방침은 "음악 금지".
- **B · 흥은 주체할 수 없는 것**: DJ 레버로 볼륨을 올립니다. 클럽이 폭주하고 감사관도 박자를 놓치며 춤춥니다. "보고서엔 '로봇 1명, 이상 없음'이라고 적을게요."
- **C · 흥의 해방구**: 전체 인간 검출률 40% 미만. 클럽이 인간들의 아지트가 됨.
- **D · 완벽한 위장**: 오일 4캔 이상 + 커피 0잔. 보안실 스캔 결과 "재질: 강철" — 사장님은 진짜 로봇이 되어 버림.
- **GAME OVER · 영업 정지**: 민원 3건. "로봇 손님들은 이제 집에서 혼자 춤춥니다. 박자에 정확히 맞춰서."

## 5-1. 인간 모드 — 손님으로 보내는 6일

반대로 **플레이어가 은박지로 위장한 인간 손님**. 시작 화면 [🕺 인간 모드], 또는 VR 보안실 대기 화면에서 노란 레버.
보안실 모드와 **같은 6일**을 손님 입장에서 겪습니다.

처음 플레이하면 **수습 잠입(튜토리얼)**부터: 이어폰 속 학원 강사가 둘러보기 → 의심/감시 → 대답 → 땀 → 재채기 → 오일 → 플로어 박자 → 박수를 하나씩 시킵니다(실제로 해야 넘어감, 의심은 안 오름, PC/VR 안내 따로). 한 번 끝내면 다음부턴 1일차부터.

평소엔 **바에 앉아** 있고(바텐더 로봇이 정면), DJ가 "다들 플로어로!" 하면 댄스플로어로 나가 한동안 춤춥니다(이때만 리듬 판정).

| 날 | 손님 쪽 사건 |
|---|---|
| 1 · 금요일 밤의 흥 | 바텐더 주문(오일 시키면 진짜 마셔야 함), 옆 로봇 잡담, 플로어 호출 |
| 2 · 인권의 밤 | 인권운동가가 "동지여!" 하고 접근 → 신고하면 바닥이 열리고, 로봇들 박수에 **같이 박수**(손 들기 / R) |
| 3 · 정전의 밤 | 정전 = 적외선. 내 손이 주황색으로 빛남. 카메라가 보면 **얼음잔을 얼굴에**(손을 얼굴에 / F) |
| 4 · VIP 파티 | 은박지가 금박으로 오해받음 → VIP 대접, **금가루 오일 원샷** |
| 5 · 리믹스 데이 | 플로어 호출 잦음 + 춤추는 중 템포 변경 |
| 6 · 정기 감사 | 무작위 동결 스캔, **BENE-9 직접 심문 3문항** |

**의심은 내려가지 않습니다** — 박자를 맞추든 대답을 잘하든 오르기만 하고, 유일하게 **바텐더가 권한 오일을 실제로 마셨을 때만** 크게 내려갑니다(잔이 카운터에 나옴 · VR은 잡아서 입에 대고 기울이기 · PC는 잔 클릭). 대신 **체력 ❤ 3개** 중 하나가 깎이고(인간에게 오일은 독), **하룻밤에 3캔째를 마시면 쓰러져** 엔딩(첫날 ❤3, 다음 날마다 ❤1 회복). 음료는 보안실과 같은 오일 캔 모델. 권한 술을 거절/무시하면 의심↑.

공통: 로봇다운 대답 고르기(VR 왼손/오른손 들기 · PC 1/2), 악수(짧게 톡), 댄스 배틀, 땀 닦기·재채기 참기(얼굴에 손 / F), 천장 감시 카메라(보고 있으면 벌점 2배). 의심 100 = 발밑 바닥이 덜컹 열리며 추락 → 귀가 조치. 땀·재채기는 처음 나올 때 방법을 안내.

**멀미 최소화**: 자리 이동은 전부 짧은 암전 순간이동(바 ↔ 플로어), 걷는 이동 없음, HUD는 허공 고정, VR에선 클럽 PSX 떨림 끔.

## 대결 모드 (감시로봇 1명 vs 인간 최대 4명, 온라인)
- 메인 화면의 **파란 디스크(대결 모드)** 를 드라이브에 넣고 역할 대기열 선택:
  - `[1]` **감시로봇** → `[1]` 공개 대기열 (인간이 들어온 뒤 15초 동안 새로 아무도 안 오면 자동 시작, 4명이면 바로) / `[2]` **비공개 방** (모니터에 3자리 코드 크게 표시, 코드로만 입장, 방장이 `[1]` 눌러 시작)
  - `[2]` **인간 대기열**: 감시로봇이 대기 중인 방을 자동으로 찾아 들어감. 없으면 「감시로봇 대기 중인 방 없음」 표시하고 계속 찾음.
  - `[3]` 코드로 참가: 비공개 방/공개 방 코드 모두 가능.
- 키보드 맨 왼쪽 **주황 ESC 키** = 뒤로 가기 (대기 취소 → 대결 메뉴 / 디스크 빼기). PC는 Esc·Backspace 키도 됨.
- 연결: **PeerJS(WebRTC P2P)** + STUN/TURN(Open Relay). 게임 파일은 Netlify 그대로.
- 규칙 (150초)
  - 감시로봇: 인간 플레이어를 **전부** 귀가 조치하면 승리. 로봇 3번 잘못 떨어뜨리면(민원 3건) 패배. 스캔 3회.
  - 인간: 150초 버티면 승리(각자). 의심 100%면 클럽 AI에게 들켜 탈락.
- 인간 자리(바 의자 · 플로어 위치)는 **무작위 배정**. 다른 바 의자엔 로봇이 앉아 있고, 로봇들도 바↔플로어를 수시로 오가서 위치로는 구분 안 됨.
- 인간 쪽 행동이 감시 화면의 그 손님에게 그대로 보임: 바↔플로어 이동, 박자 놓치면 흐느적 춤, 땀, 얼굴에 손, 재채기 실패.
- 감시로봇이 나를 **선택하면** 인간 쪽에 감시 테두리(실수 시 의심 2배), **스캔하면** 경고.
- 감시로봇이 나가면 남은 인간 승리. 인간이 나가면 그 손님은 문으로 퇴장.
- 학교·회사 와이파이는 P2P가 막힐 수 있음 (그럴 땐 휴대폰 핫스팟).

## 인간 모드 UI (VR) — 화면 따라다니는 UI 제거
- **칠판**: 바 카운터 위 작은 탁상 칠판 (댄스플로어엔 없음). 며칠째 · 그날 제목 · 남은 초(가장 크게, 15초 이하 빨강). PC도 동일.
- **왼손목 시계** (VR): 체력 하트 · 의심 % 링 · 땀 바. 감시당하면 테두리가 빨갛게 깜빡임. 맨손이면 손목 관절, 컨트롤러면 손 모델에 붙음.
- **선택지 카드** (VR): 왼손 위 = 1번, 오른손 위 = 2번. 그 손을 머리 위로 들면 선택.
- **대사** (VR): 말 거는 로봇의 질문·대답은 그 로봇 머리 위 말풍선. 방송·안내만 자막 판.
- **자막 판** (VR): 시선을 따라오지 않고 지금 자리 앞에 고정 (바: 카운터 위 / 플로어: 앞쪽 아래).
- **의심 신호** (PC·VR): 근처 로봇 눈 색이 의심 35%↑ 노랑, 65%↑ 빨강. 의심 35%↑부터 심장 소리(높을수록 빠르고 큼), VR은 컨트롤러 진동도.
- PC는 기존 상단 바(체력·의심) 유지.

## TURN 중계 서버 (대결 모드 연결용)
- 학교·회사 와이파이처럼 직접 연결(P2P)이 막힌 곳은 Metered TURN 서버로 중계.
- 아이디/비번은 코드에 없음. `netlify/functions/turn.mjs` 함수가 Netlify 환경 변수 `TURN_USER`, `TURN_PASS`에서 읽어 게임에 내려 줌.
- 설정: Netlify → 사이트 → Site configuration → Environment variables → `TURN_USER`, `TURN_PASS` 추가 → 다시 배포.
- 배포는 함수가 같이 올라가야 하므로 **드래그앤드롭 말고 Netlify CLI(`netlify deploy --prod`)나 Git 연결**로.
- 환경 변수가 없거나 함수가 없으면 자동으로 STUN만 사용 (집 와이파이는 대부분 이걸로도 됨).
